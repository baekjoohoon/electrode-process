## 설명 (5,000자 이내)

12개의 도미노를 소개하는 한 장짜리 랜딩 페이지입니다.

이 페이지의 도미노는 그림이 아니라 계산입니다. 외부 물리 라이브러리 없이 직접 작성한 2D 강체 엔진이 브라우저에서 실시간으로 도미노 12개를 풀고 있습니다. 위치·각도·선속도·각속도를 가진 강체, SAT 분리축 정리와 꼭짓점 접촉으로 충돌을 찾고, 접촉 마진으로 살짝 닿은 상태를 유지하며, 누적 임펄스를 다음 스텝으로 넘기는 웜 스타트와 협력적 임펄스로 정지 상태를 안정화했습니다. 쿨롱 마찰, 240Hz 고정 스텝, 침투 보정까지 들어 있습니다. 하단의 계측값(넘어짐·최대 각도·충돌 횟수·경과 시간)은 모두 그 시뮬레이션의 실제 값입니다.

방문자가 할 수 있는 일은 네 가지입니다. 도미노를 누르면 그 자리에서 연쇄가 시작되고, 끌면 받침점을 축으로 기울어 손을 뗀 힘대로 넘어갑니다. '밀어보기' 버튼과 '다시 세우기' 버튼, 그리고 스크롤. 스크롤은 단순한 이동이 아니라 무대 카메라를 끌고 갑니다. 스크롤이 처음 임계점을 넘으면 첫 도미노가 자동으로 넘어가고, 붉은 파동이 도미노를 타고 오른쪽 끝까지 이동합니다. 넘어지는 순서에 맞춰 각 섹션이 열리므로, 설명을 읽는 동안 도미노가 그 설명을 대신 수행합니다.

화면 왼쪽 끝에는 두 번째 무대가 있습니다. 미니 도미노 12개가 세로로 매달린 레일로, 페이지를 읽는 위치가 임계점을 넘을 때마다 위에서부터 하나씩 실제 각도 적분으로 넘어집니다. 글을 되돌려 올라가면 다시 일어섭니다. 하단 무대가 '제품의 연쇄'라면 이 레일은 '읽는 진척'을 같은 물리로 보여 줍니다.

도미노가 부딪히는 소리는 Web Audio로 그때그때 합성합니다(음원 파일 없음, 기본 꺼짐).

한 장 규칙을 지키기 위해 페이지는 하나이고, 다른 주소로 넘어가는 링크는 없습니다. 스크롤 진행에 묶인 등장 연출은 CSS scroll-driven animations(animation-timeline: view())로 처리하고, 미지원 브라우저와 prefers-reduced-motion에서는 IntersectionObserver 경로로 대체합니다. 무대 높이는 화면 크기와 비율에 따라 다시 계산되어, 히어로에서는 화면의 42%(모바일 44%)를 쓰고 스크롤하면 29%(31%)까지 줄어 본문을 가리지 않습니다. 도미노는 두께 18mm·높이 100mm로 실제 도미노와 같은 1:5.5 비율입니다. 서체는 Pretendard를 사용 글자만 남겨 자체 호스팅(90KB)했고 OFL 1.1 전문을 저장소에 포함했습니다. 외부 라이브러리·이미지·음원·영상은 사용하지 않았습니다.

도미노는 한 번 넘어지면 끝이지만, 이 페이지는 '다시 세우기'로 몇 번이든 다시 넘길 수 있습니다.
