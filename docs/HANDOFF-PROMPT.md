- 문장 톤: 짧고 단정하게. 과장·감탄 금지, 숫자로 말한다.

## 4. 디자인 요구 — 이게 핵심이다

사용자가 "강렬하고 좋다"고 말한 참고 페이지: **`https://fdethon.beyonddeploy.kr/`** (Next.js, 자산 없음, 폰트 6개)

그 페이지 CSS에서 추출한 실제 값:

| 항목 | 값 |
|---|---|
| 최대 글자 | `clamp(140px, 26vw, 380px)` |
| 섹션 제목 | `clamp(26px, 6.2vw, 90px)` |
| 본문 | `clamp(16px, 1.8vw, 24px)` |
| 자간 | −0.015 ~ −0.045em |
| 팔레트 | `#171717` `#f4f2ec` `#26251f` — **무채색 2~3개** |
| 서체 | Pretendard Variable(한글) + Instrument Serif(라틴 세리프) + Fragment Mono(라벨) |
| 모션 | 마퀴, 글리치 지터, CTA 호흡, 진입 스태거 등 다수 |

**요구 사항**
1. **타격감** — 첫 화면에 하나의 주장이 화면급 크기로. 글자가 화면 폭을 거의 다 쓴다. 작은 글씨 남발 금지.
2. **화려함** — 색이 아니라 **크기·서체·모션·밀도**에서 만든다. 무채색 + 포인트 한 색.
3. **시안성** — 라벨 하한 12px 이상, 대비 확보, 장식용 작은 글씨 금지.
4. **참고하되 베끼지 말 것.** 구조·수치·문법의 *크기*는 참고하되, 레이아웃과 아이덴티티는 이 주제에서 새로 만들어라. (사용자가 "배끼지 말라"고 명시했다.)
5. 애니메이션은 **첫 화면에서 즉시 보여야** 한다(심사 배점 15점).

## 4.5 차별화 요구 (필수) — 참고 페이지와 "다른 작품"으로 보여야 한다

참고 페이지에서 **서명처럼 보이는 4가지는 그대로 가져오지 말 것.** 심사위원이 그 페이지를 봤다면 창의성(15점)에서 즉시 손해다.

| 참고 페이지의 서명 | 우리가 할 것 |
|---|---|
| 거대 한글 산세리프 **문장**이 화면을 지배 | 화면 최대 요소를 **실시간 측정값(숫자)** 으로. 문장은 작고 기술적으로(모노 12~14px) |
| 어두운 웜뉴트럴 + 크림 | 재료의 색(흑연·구리) 또는 **밝은 종이(랩 리포트) + 검정 잉크 + 구리** — 참고와 정반대 톤 |
| **마퀴**(무한 흐르는 띠) | **마퀴 금지.** 스크롤이 곧 재료의 시계를 돌린다(스크롤 = 건조 경과 시간) |
| Instrument Serif + Fragment Mono | 다른 조합(OFL): 한글 Pretendard + 라틴/숫자용 그로테스크·모노를 자체 서브셋 |

**핵심 전환: "문장이 큰 페이지" → "측정값이 큰 페이지".**
우리 주장은 말이 아니라 숫자다(같은 반죽 30초에 표면 바인더 5.66배 vs 2.19배). 그러므로 가장 큰 요소가 **살아 움직이는 숫자**인 것이 내용과 일치한다. 히어로에서 그 숫자가 실시간으로 변하고, 스크롤하면 조건이 바뀌어 값이 갈라진다.

**합격 기준(육안)**: 참고 페이지를 옆에 놓고 봤을 때 "같은 템플릿"으로 보이면 실패, "다른 작품"으로 보이면 통과.

## 5. 기술 요구

- **단일 파일 권장**(`public/index.html`), 외부 라이브러리 없이. (라이브러리를 쓸 거면 사용자에게 먼저 물어라 — 차별화 전략이 "직접 구현"이었다.)

- 콘솔 오류 0. 4배 CPU 감속에서 60fps 근처.
- 모바일에서 애니메이션·인터랙션이 살아 있어야 한다(배점 8점).
- 접근성: `prefers-reduced-motion` 존중, 슬라이더 라벨 연결.

## 6. 하지 말 것 (실패 기록 — 같은 실수 반복 금지)

1. **글자와 그림을 같은 자리에 겹치지 말 것.** 참고 페이지의 "겹침"은 글자 위에 글자를 의도적으로 포갠 것이지, 데이터 그림 위에 글자를 얹는 게 아니다. 위반 사례: 223px 제목을 재료 단면 위에 얹어 사용자가 "겹쳤다"고 지적받음.
2. **그림 두 개가 테두리를 공유하지 말 것** — 각 패널에 내부 여백 + 가운데 거터.
3. **정의되지 않은 변수·TDZ 금지.** 초기화 순서 문제로 페이지가 첫 프레임부터 죽은 적 있음(`dt is not defined`, `Cannot access 'primeLeft' before initialization`). 프레임 루프 첫 줄에 `requestAnimationFrame`을 다시 걸고 본문을 `try/catch`로 감싸라(루프가 죽지 않게).
4. **"살아 있다"를 HUD 숫자로 판단하지 말 것.** 시뮬레이션 시계(`probe().t`)가 실제로 증가하는지, 캔버스 픽셀 해시가 프레임마다 변하는지로 검증하라.
5. **자동 서술 모델의 "8/10"을 근거로 쓰지 말 것.** 그런 모델은 한글을 틀리게 읽고 없는 요소를 만들어낸다(실제로 "겹침 0"인 화면에 "심하게 겹침"이라고 답했다). 판단은 사용자에게, 검증은 수치로.
6. 한 장 규칙 위반 링크·미승인 제출·미검증 자산 사용 금지.
